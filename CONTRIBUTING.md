# Contributing and feedback

Mani's Room is a personal creative project and learning space. Thoughtful feedback is welcome, particularly about accessibility, responsive behavior, documentation, and user experience.

## Before opening an issue

Please search existing [issues](https://github.com/GitWithMani/manis-playground/issues) and include:

- The page or feature involved
- What you expected and what happened
- Steps to reproduce, if reporting a bug
- Browser/device information, when relevant
- A suggested improvement, if you have one

Do not post personal data, credentials, or screenshots containing sensitive information.

## Proposing a change

For substantial changes, open an issue first to discuss scope. For small fixes, fork the repository, create a focused branch, make the change, test it, and open a PR explaining the change and validation.

Please do not replace original photography, playlist links, brand copy, or design direction without discussing it first. AI-assisted contributions are welcome if accurately disclosed and reviewed. Do not introduce new dependencies or third-party assets without approval.

## Rights

This repository does not currently include an open-source license. Public visibility is not permission to reuse the site's original images, artwork or code. Contributions may be reviewed, but permission to reuse material must be obtained separately.
