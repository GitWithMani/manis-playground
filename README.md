# Mani's Room

*A space for the sonically curious.*

[Visit the live site](https://gitwithmani.github.io/manis-playground/) · [Explore the Listening Room](https://gitwithmani.github.io/manis-playground/listening.html)

Mani's Room is a personal music-and-photography website designed as a collection of intimate creative rooms. It began as a first Git/GitHub and VS Code practice project and grew into a published, multi-page frontend site through iterative AI-assisted development.

## What you can explore

- **Home:** An editorial entrance with original portrait photography and introductions to the site's rooms.
- **The Listening Room:** Three curated Apple Music playlists—*Donell vs Joe*, *Where Ma Girls At*, and *For Pat*—presented as interactive record sleeves with one official Apple Music embed.
- **The Gallery:** A preview of a future photography collection.
- **On Air:** A clearly labeled placeholder for a future radio experience; there is no live broadcast yet.

## Built with

HTML5, CSS3, vanilla JavaScript, Apple Music's official embeds, Git/GitHub, GitHub Pages, VS Code, and Codex as an AI coding collaborator. No frontend framework is required.

## My role and development process

I defined the creative direction and functional requirements; selected the original images and playlists; directed Codex through iterative prompts; reviewed the resulting changes; previewed layouts in Safari; requested refinements; and managed pull requests and merges. Codex generated or edited portions of the implementation. I do not present AI-generated code as entirely hand-written.

The project emphasizes accessible semantic markup, keyboard-aware controls, reduced-motion support, native browser scrolling, responsive layout, and preserving working behavior during redesigns. Automated checks documented in PRs are not a substitute for comprehensive cross-browser or assistive-technology testing.

## Local preview

Clone the repository, then open `index.html` in a browser. The site uses relative asset paths and does not require a build step. Apple Music embeds require an internet connection and may be subject to Apple's playback restrictions.
